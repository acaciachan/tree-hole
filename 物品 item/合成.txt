 【简单合成】
 无中间合成，可随时激活合成器：
	9合1(可逆)
		粘液球、树脂团
		红石粉、绿宝石、煤炭、粗矿
		干海带、小麦(干草块)、西瓜片

	9合1(不可逆)
		竹子 -> 竹块
		冰->浮冰->蓝冰
		下界疣，粗矿(合成块)，硫磺(合成烈性硫磺)

	4合1(半可逆)
		黏土球 -> 黏土块
		雪球 -> 雪块

	4合1(不可逆)
		线 -> 羊毛
		海晶碎片 -> 海晶石
		石英，岩浆膏，树脂砖，萤石，下界砖，滴水石锥

	3合1(不可逆)
		雪块->雪片
	2合1
		竹子 -> 木棍
	1合1

存在中间合成，必须检测信号或严格维持输入和输出比例：
	9合1：铁、铜、金锭 -> 块
	3合1：甘蔗 -> 纸
	1合1：各种小型花 -> 1染料
	1合2：各种大型花 -> 2染料
特殊配方合成：
	2原木 + 2贝壳 -> 1箱子 + 2贝壳 -> 1盒子
	3骨头 -> 9骨粉 -> 1骨块
	5:4合成：海晶灯、TNT
	4蜂蜜瓶 <-> 1蜜块 + 4空瓶

三废岩：
2圆石 + 2石英 -> 2闪长岩
1闪长岩 + 1圆石 -> 1安山岩
1闪长岩 + 1石英 -> 1花岗岩
